luggage, clothing, shoes and accessories. Directory inclusion does not prove

recorded separately. They are clearly marked illustrative and are never
presented as authentic products of an international brand. No third-party
logo files or copied product photography were incorporated.

Each product has the Arabic action `تواصل عبر واتساب لمعرفة السعر`, with an
equivalent English action. The preview has no verified contact destination;
the action therefore opens a local dialogue containing the piece's reference
and a copyable inquiry. It does not send a message. Live mode requires explicit
configuration with a verified business number.
