# Project overview

## Purpose

`jwleria` is the canonical jewelry commerce project. Its public repository may document public-safe storefront behavior and generic application integrations.

## In scope

- public code and product documentation already appropriate for this repository
- generic storefront, application, and commerce integration guidance
- public-safe state, handoff, and decisions
- history-preserving repository reconciliation documentation

## Out of scope

- private business strategy and operational memory
- credentials, tokens, or production configuration
- customer, order, supplier, or financial records
- private assets and raw conversations
- unreviewed content from `jwleria-s-gembox`

This overview does not authorize deployment, production changes, repository archiving, visibility changes, or duplicate consolidation.
