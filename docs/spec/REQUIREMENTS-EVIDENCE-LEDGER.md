## Remaining delivery, in order

The website milestone is photographs. The rest of the foundation is live: catalogue, models and variants, cards and product pages, credits and the phone layout. Two items outside the list: the cache labels HIT and STALE are unobserved, and contact (R1's WhatsApp number) is deferred by the owner and is not a gate. This list names only what is left and sets no completion date: photo coverage depends on rights holders' answers.

1. **Real exact photographs.** Get a rights basis for exact images. Start with the open sources whose galleries name the reference: Rolex 1,465, Prada 851, LOEWE 407, Longchamp 371 and Bottega Veneta 8 public products. The basis is written permission covering publication, resizing, WebP and background removal, plus the owner's source publication flag; or the owner's own photographs. Then run the existing pipeline per product: originals, identity check, bundle, upload, publish. Today: 1 of 4,097.
2. **Cutout matching and optimisation.** Check each held original for existing transparency. If it has none, and its rights allow an adaptation, make a background-only master with a tool that does not redraw. Run `cutout.mjs`, then the independent visual comparison. When the first cutout is accepted, prepare the reviewed enabling change: database evidence for the master and treatment, the credit text, and the storefront's Arabic for it.
3. **Category and variant coverage.** Cover every displayed model's primary variant first (2,886 models), then the other variants. Each variant gets its own exact photo, never a sibling's.
4. **Photo-filled mobile performance.** With real photographs, measure catalogue and product pages at 360/390/430 px: bytes, LCP and CLS, labelled as lab numbers. Observe the cache labels HIT and STALE (runbook CA-1).
