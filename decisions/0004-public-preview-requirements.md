# 0004 — Begin the inquiry-only public catalog preview

Status: accepted for local reviewable implementation; production release pending

Date: 2026-10-03

The owner authorized beginning a visual website preview with these requirements:

- No country/region selection, public amounts, currencies or monetary filtering.
- Every product card and detail provides an inquiry action. Arabic label:
  **تواصل عبر واتساب لمعرفة السعر**.
- Open browsing without login, account, administration entry, cart or checkout.
- Expandable international brand directory across luxury, accessible luxury and
  contemporary tiers. Directory inclusion alone does not establish availability.
- Categories include watches, bracelets, jewelry, leather goods, handbags,
  luggage, clothing, shoes and accessories.
- Editorial premium imagery and a fast mobile experience.

Build the public UI against a typed synthetic fixture adapter now. Prepare the
data contract in parallel; connect the live database after presentation review.
The initial static preview is not the final server-rendered production adapter.

Synthetic products belong to a neutral preview collection, never to an actual
international brand. Synthetic images must remain clearly identified and must
not be presented as an exact branded product. Real media/content batches and
the business contact destination must be verified before launch.

This authorization permits local reversible implementation. It does not approve
public publication, production database writes, account/billing changes, DNS,
scraping, ad campaigns or migration promotion. Historical source is preserved.
