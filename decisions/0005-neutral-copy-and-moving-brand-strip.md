# 0005 — Neutral catalog copy and a moving brand strip

Status: accepted for the local preview

Date: 2026-10-03

The owner explicitly removed personal-shopping wording from the visitor
experience and requested a continuously moving brand-name strip. Apply the
copy correction to both locales, metadata, footer, about page and inquiry
defaults. Use neutral language about selections, products and inquiries;
retain accurate independence/non-affiliation wording without describing the
business model in those labels.

The home strip loops brand names and retains their directory links. Provide
pause/resume, pause on pointer hover, keyboard navigation and a nonanimated
scrollable fallback when reduced motion is preferred. Repeated visual names
must not duplicate assistive-technology or sequential-keyboard entries.

This is a presentation correction to the local preview. It does not enable
production publishing or change the existing public-data/contact boundaries.

The owner's subsequent correction requires Arabic visitor copy to address women
and men without masculine second-person forms. The hero is now
`الفخامة، بكل تفاصيلها`; actions and instructional copy use neutral noun-based
wording. The current product action is `التواصل عبر واتساب لمعرفة السعر`,
superseding the earlier label in decision 0004 while preserving its purpose.
